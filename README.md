# Stats in Python — DA Portfolio Project

## Overview
End-to-end statistical analysis on e-commerce orders data using Python.

## Concepts Covered
- Descriptive Stats (mean, std, skewness, kurtosis , percentile , iqr , outliers)
- Normal Distribution check (scipy normaltest)
- Binomial Distribution (ad click rate analysis)
- Poisson Distribution (orders per hour analysis)
- Hypothesis Testing (t-test, p-value)
- Confidence Intervals
- A/B Testing (UI experiment simulation)
- Correlation Analysis + Heatmap

## Tech Stack
Python, Pandas, NumPy, SciPy, Seaborn, Matplotlib

## Dataset
Simulated e-commerce dataset — 1000 orders across Delhi, Mumbai, Bangalore
